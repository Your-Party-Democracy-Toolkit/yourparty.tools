# Contributing

Thanks for helping build **yourparty.tools** — a public, democratic organising toolkit.

## How we work
- **Markdown-first**: edit files in `/content`. Use clear headings and short paragraphs.
- **Front-matter**: every page has `title`, `description`, and `updated` (ISO date).
- **Tone**: practical, inclusive, movement-oriented; no sectarianism, no harassment.
- **Licensing**: propose CC BY-SA 4.0 unless noted otherwise.

## Proposing changes
1. Fork the repo, create a branch, make edits.
2. If adding a new page, include a short summary in the PR description.
3. PRs are reviewed by maintainers for clarity, safety, and duplication.
4. Once merged, Vercel auto-deploys.

## Reports
- Use the **Report in!** form (on the site) or add a Markdown file under `/content/reports`.
- Set `approved: false`; editors will review and flip to `true`.
